# 군외중 바이브코딩 실습 가이드

중학생 대상 100분 바이브코딩 실습 강의를 위한 **슬라이드 앱**입니다.
**우리 학교가 배경인 게임을 만들고 → 깃허브에 올리고 → Vercel로 배포하고 → DB에 기록을 저장하는** 전 과정을 52장의 슬라이드로 담았습니다.

- 일시: 2026. 9. 7. / 100분 연강
- 대상: 중학생 약 20명
- 강사: 선영욱 (장흥 관산중 · 사회/역사)
- 실습 환경: 전남 아이모두 학생용 제미나이 Canvas
- 배포: https://gunoe-vibe-guide.vercel.app

## 구성

| 섹션 | 슬라이드 |
|---|---|
| 시작 | 타이틀 · 오프닝 훅 · 선배 작품 링크 · 오늘의 목표 흐름도 · 타임테이블 |
| 원리 | "웹 서비스는 어떻게 작동할까?" 구조 그림 · 프론트/백엔드/DB · 깃허브→Vercel · 바이브코딩 · 확인 질문 |
| STEP 1~6 | 각 단계 인트로(흐름도에서 현재 위치 강조) → 클릭 단위 절차 → 복사 가능한 프롬프트 → 🎤 강사 대사 |
| STEP 1-3 | **프롬프트 작성 6가지 키워드**(Anthropic 프롬프팅 가이드 요약: 역할·내용+이유·칸 나누기·구체적·예시·해줘·확인) → 키워드를 줄마다 태그로 표시한 예시 프롬프트 |
| STEP 6 심화 | 시간이 남을 때 학생이 **자기 Supabase를 직접 만들어** 리더보드를 갖는 5단계(가입 → rankings 표 → RLS 정책 2개 → anon 키 복사 → 코드 연결) + 안 될 때 점검표 |
| 마무리 | 전원 랭킹전 · 오늘 배운 것 · 마지막 한 마디 · 심화(급식표 앱) |
| 강사용 | 모델 선택 근거(모켓 랭킹) · 사전 준비 체크리스트 · Plan B · 리스크 대응표 |

## 강의 중 조작

- `←` `→` 또는 `Space` 로 넘기기, `Home` / `End` 로 처음·끝
- `T` 목차, `F` 전체 화면, `Esc` 닫기
- 모바일은 좌우 스와이프
- 상단 **타이머**: 눌러서 분·초를 스크롤로 맞추고 시작합니다. STEP별 시간 프리셋(22·8·5·17·10분)이 있고, 남은 시간이 25% 이하면 주황, 10% 이하면 빨강, 0이 되면 **알림음**이 울립니다(음악 파일 없이 Web Audio API로 생성 — 수업에서 학생에게 가르치는 그 방식). 새로고침해도 이어집니다
- 주소의 `#번호`가 현재 슬라이드라서 새로고침해도 그 자리로 돌아옵니다

## 내용 수정

- 슬라이드 본문: [`src/data/slides.js`](src/data/slides.js) — 한 장이 객체 하나. `type`에 따라 레이아웃이 정해집니다.
- 강사용 자료: [`src/data/lecture.js`](src/data/lecture.js)
- 원리 그림: `public/web-structure.jpg`

수업 직전에 STEP 6 프롬프트의 `Supabase URL` / `anon key` 자리를 실제 값으로 바꾸면 됩니다.

## 실행

```bash
npm install
npm run dev
```

빌드는 `npm run build`, 결과물은 `dist/`에 생성됩니다. `main`에 push하면 Vercel이 자동으로 재배포합니다.

## 기술

React 19 + Vite. 라우터·상태 라이브러리 없이 단일 컴포넌트 트리입니다.
디자인 팔레트는 원리 그림의 민트·딥그린을 따릅니다.

## PDF · PPT로 내보내기

`?print=1`을 붙이면 52장이 한 페이지에 하나씩 쌓인 인쇄용 화면이 나옵니다.
`from`/`to`로 구간을 자를 수 있습니다(크롬은 문서가 너무 길면 인쇄에 실패하므로 나눠 뽑습니다).

```bash
# 예: 0~8번 슬라이드만
open "https://gunoe-vibe-guide.vercel.app/?print=1&from=0&to=8"
```

브라우저에서 `Cmd/Ctrl + P` → 용지 13.333 x 7.5in(16:9), 배경 그래픽 켜기, 여백 없음으로 저장하면 됩니다.
완성본은 저장소 바깥의 강의 폴더에 있습니다.
