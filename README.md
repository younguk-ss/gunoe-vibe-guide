# 군외중 바이브코딩 실습 가이드

중학생 대상 100분 바이브코딩 실습 강의 자료 앱입니다.
**우리 학교가 배경인 게임을 만들고 → 깃허브에 올리고 → Vercel로 배포하고 → DB에 기록을 저장하는** 전 과정을 학생이 직접 따라 할 수 있도록 구성했습니다.

- 일시: 2026. 9. 7. / 100분 연강
- 대상: 중학생 약 20명
- 강사: 선영욱 (장흥 관산중 · 사회/역사)
- 실습 환경: 전남 아이모두 학생용 제미나이 Canvas

## 구성

| 화면 | 내용 |
|---|---|
| 개요 | 오늘의 목표, 100분 타임테이블, 페이스 기준점, 작동 원리, 사례 링크 |
| STEP 1 | 게임 만들기 — 시작 프롬프트 + 다듬기 프롬프트 4종 |
| STEP 2 | 배경 사진을 픽셀아트로 — 디자인 3단계 원칙 |
| STEP 3 | 배경 연결 + 파일 저장 — ⭐ "안 보이는" 순간과 강사 대사 |
| STEP 4 | 깃허브에 올리기 (push) — 가입부터 업로드까지 클릭 단위 안내 |
| STEP 5 | Vercel로 배포하기 — 배경이 나타나는 순간 |
| STEP 6 | DB 연결 — 반 전체가 공유하는 랭킹보드 |
| 심화 | 급식표 피드백 앱 등 확장 과제 |
| 강사용 | 모델 선택 근거, 사전 준비 체크리스트, Plan B, 리스크 대응표 |

## 기능

- **프롬프트 복사 버튼** — 학생이 긴 프롬프트를 그대로 복사해 제미나이에 붙여넣을 수 있습니다
- **진행 상황 저장** — 완료한 STEP과 준비 체크리스트를 브라우저에 기억합니다
- **다크 / 라이트 전환** — 교실 조명 환경에 맞춰 전환합니다
- **모바일 대응** — 학생이 폰으로 따라 볼 수 있습니다

## 실행

```bash
npm install
npm run dev
```

빌드는 `npm run build`, 결과물은 `dist/`에 생성됩니다.

## 기술

React 19 + Vite. 외부 상태 관리나 라우터 없이 단일 컴포넌트 트리로 구성했습니다.
강의 내용은 전부 [`src/data/lecture.js`](src/data/lecture.js) 한 곳에 있으므로, 내용 수정은 이 파일만 고치면 됩니다.
